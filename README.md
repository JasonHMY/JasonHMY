### What I'm working on

**[KeepUpdated](https://github.com/JasonHMY/KeepUpdated)**  
A Mac software manager for apps, Skills, MCP installations and developer tools. See what's installed, check for updates, and review supported changes before running them. Still in development.

**[Personal Finance Visualizer](https://github.com/JasonHMY/personal-finance-visualizer)**  
An agent skill that turns finance records into an interactive report you can open locally. Explore spending, income and transfers, then click through to the transactions behind each total. Supports English and Chinese.

### Other projects
